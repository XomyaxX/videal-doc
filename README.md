# Videal.Doc

Студийный CRM / ЭДО для анимационного продакшена. Боевой инстанс крутится в офисе ООО «Videal-Media»; публичный вход — [videal-doc.ru](https://videal-doc.ru) (учётки только у сотрудников).

Этот репозиторий — исходники системы как портфолио. База, загруженные файлы, `.env` и внутренние деплой-секреты сюда не входят.

## Стек

- **Next.js 16** + **React 19**
- **Prisma 6** + SQLite
- PDF (авансовый АО-1, заявки на выдачу денег), QR чеков ФНС, SMTP/IMAP
- systemd + nginx в офисе, TLS на внешнем VPS

## Что умеет

- Сотрудники, роли, отделы, несколько учёток на одном компьютере
- Документооборот: рассылка, ознакомление, скан с подписью
- Производство: сериал → серия → сцена → шот, две пайплайн-схемы
  - **3D Superглазка (E02):** сценарий / режиссура / концепт, аниматик, блокинг, анимация / липсинк / эмоции, ассеты персонажей
  - **ИИ-мультфильм:** сценарий / раскадровка / концепт / монтаж, первый кадр и генерация видео
- Задачи: чат по задаче, дедлайн, переименование, соседние этапы, корзина
- Совещания: созвон (шаринг, чат комнаты), запись → расшифровка → сводка, доступ по ACL
- Чат: голос с расшифровкой, вложения, 3D-превью (GLB / конвертация blend через Blender)
- Авансовые отчёты, заявки АХО, библиотека файлов, склад, календарь, почта

## Локальный запуск

Нужны Node.js 20+ и npm.

```bash
cp .env.example .env
npm install
npm run setup
npm run dev
```

Откройте http://localhost:3000

Сиды создают демо-админа `admin` с временным паролем `Videal2026!` — система сразу просит сменить его. Это только для локальной базы, не прод.

## Переменные окружения

См. `.env.example`:

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | SQLite, по умолчанию `file:../data/videal.db` |
| `FILE_ROOT` | Каталог загрузок |
| `SESSION_SECRET` | Секрет сессий — задайте свой |
| `SHARE_ROOT` | Опционально, сетевая шара |
| `GROQ_API_KEY` | STT записи совещания (Whisper). Без него сводка не стартует |
| `DEEPSEEK_API_KEY` | Сводка и предлагаемые задачи (основной LLM) |
| `DASHSCOPE_API_KEY` | Запасной Qwen, если DeepSeek 429 |
| `GEMINI_API_KEY` | Сводка и правка расшифровки (через прокси) |
| `TURN_URLS` / `TURN_USER` / `TURN_PASS` | TURN для созвона из дома |

Как завести ключи — `docs/grok-bot-api-keys.md`.

### Совещания: как проверить

1. Созвать совещание, выбрать «кто видит» и «куда отправить сводку».
2. Войти в комнату **в одной сети** (офис): камера, шаринг экрана, «крупно», «на весь экран», чат справа. Созвон свой, WebRTC, без Jitsi.
3. Организатор грузит тестовый mp3 на карточке. Статус: обрабатывается → сводка готова.

Скрипты `scripts/deploy.mjs` / `scripts/ssh.mjs` ходят на офисный сервер. Пароль SSH **не зашит в код**: перед запуском задайте `SSH_PASS` (и при необходимости `SSH_HOST`, `SSH_USER`).
